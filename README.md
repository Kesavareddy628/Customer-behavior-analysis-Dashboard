# Customer Behavior Analysis | Data Analytics Project

## 📌 Project Overview

This project analyzes customer shopping behavior to identify patterns in sales, revenue, customer demographics, subscription status, product categories, shipping preferences, and customer ratings.

The project follows a complete data analytics workflow, including:

- Data loading
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- SQL-based data analysis
- Power BI dashboard development
- Business insights and reporting

The final result is an interactive **Customer Behavior Dashboard** that helps understand customer purchasing patterns and business performance.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze overall customer purchasing behavior
- Understand sales and revenue by product category
- Compare customer behavior across different age groups
- Analyze subscription and non-subscription customers
- Understand customer ratings
- Analyze sales performance across product categories
- Identify patterns in customer purchasing behavior
- Build an interactive Power BI dashboard
- Present the findings in a simple and business-friendly format

---

## 📂 Dataset

The project uses a customer shopping behavior dataset containing information about customer purchases and demographics.

### Important Data Fields

Some of the important fields used for analysis include:

- Customer ID
- Age
- Gender
- Item Purchased
- Category
- Purchase Amount
- Review Rating
- Subscription Status
- Shipping Type
- Item Visibility
- Item Weight
- Sales
- Revenue

The dataset was cleaned and prepared before performing analysis.
